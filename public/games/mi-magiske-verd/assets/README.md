# public/assets

Final art lives here as WebP, at the exact paths in `manifest.json`. Do not put raw generator
output here; put it in `assets-work/raw/<id>.png` and run `py -3 tools/finalize_assets.py`.

- `manifest.json` — generated by `tools/build_manifest.py`; every asset id, path, size, placeholder and prompt.
- `doll/regions.json` — slot regions and anchors on the 1024×1536 doll canvas; adjust after the base doll exists.
- `doll/`, `wardrobe/`, `rooms/`, `furniture/`, `display/`, `npc/`, `stable/`, `coins/`, `icons/`, `bg/`, `decor/` — the WebP files.

The game renders a labelled placeholder for any file that is missing, so partial art is fine.
